Extraction that stores no page or quote per value cannot be audited, and a model-rated confidence score checked by nothing is not evidence.

Inherited from SpreadSense (reviewed 2026-11-17). It joined all pages into one text with no page markers, stored the model's own number and self-rated confidence, and let commentary prompts ask the model to "be specific with numbers".

Rule: keep text per page with word positions; the model returns page and printed text; code finds the text on the page and parses the number itself; no confidence score is shown unless code computed it.

Applies to: Spreading, Terms and Borrowing Base agents; commentary prompts.
