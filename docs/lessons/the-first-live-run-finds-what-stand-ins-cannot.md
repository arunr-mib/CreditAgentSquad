A stand-in reader cannot tell you how a real model phrases things; the first live run dropped two of four honest sections for wording no test had imagined.

- **What happened (18 November 2026).** The first run with a real model was the Review Agent on one borrower on the hosted link. Every figure in its answer was a fact reference, exactly as required. The strict prose check still dropped two of its four sections: "Trailing twelve-month revenue" (the number word in a measurement window) and "The certificate figures match" (a rule meant for "seven figures" matched any word before "figures").
- **Why the tests missed it.** Every test sentence was written by people who knew the rules. The stand-in reader and scripted responses never produce prose of their own, so they cannot surface a phrase a real model reaches for.
- **What changed.** Both rules were narrowed to the forms that state an amount ("seven figures", "a six-month runway" stay refused), each with tests for the live sentences and for the amounts that must still be refused. The lesson in `an-allowance-for-honest-text-is-a-hole.md` still applies: each narrowing is a possible hole, so each came with its refusal tests.
- **Rule.** Before trusting a guardrail's refusal rate, run each agent against a real model on a handful of borrowers and read every refusal. Treat a refused honest sentence as a defect with the same weight as a hole. Keep the refused text: it is the test case.
- **Also found.** A run's input was recorded as 4 tokens because the prompt was written to the cache and only uncached input was counted. Cache-written tokens now count as input; a run's cost cannot be read from a record that leaves them out.

**Again on 18 November 2026, the first live measurement (three borrowers).** Two of three cycles stopped at spreading with nothing wrong in the reading (94 of 96 statement figures right, none wrong). The page prints total equity as a total under its components; the template keeps `bs.total_equity` as a plain line; the prompt said "report every printed total under `stated.`" and "report each row of a multi-row line under the same key". The reader obeyed both: the total was refused as a `stated.` key and the two component rows were held for their labels. The stand-in reader never reads the prompt, so it could not show that two rules in it collide with the template. Fixed in the prompt (spreading version 2); the re-run on the same two borrowers read 400 of 400 figures and closed both cycles. The Intake Agent is shown two pages and told to raise a concern when pages look missing, so it reports the pages it was not shown as missing: the same kind of collision, not yet fixed.
- **Rule.** When a prompt states a rule about the page's shape, check it against the template and against what code shows the agent (page limits, which lines exist). A reader that obeys every instruction can still be stopped by two that disagree.
- **Keep the evidence.** The product records only that a note was removed. The evaluation now keeps each held figure and the agent's unshown prose (`held_cells`, `unshown_text` in the results), so the next run can be read without being repeated.
- **Replay limit.** A recorded answer that cites `{{fact:<id>}}` cannot replay: a new run writes new fact ids and the guardrail rightly refuses the old ones. Recorded mode reproduces the readers (intake, spreading, certificate, collateral) but not the Review or Early Warning agents.
