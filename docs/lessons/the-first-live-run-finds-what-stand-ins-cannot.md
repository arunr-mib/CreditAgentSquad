A stand-in reader cannot tell you how a real model phrases things; the first live run dropped two of four honest sections for wording no test had imagined.

- **What happened (18 November 2026).** The first run with a real model was the Review Agent on one borrower on the hosted link. Every figure in its answer was a fact reference, exactly as required. The strict prose check still dropped two of its four sections: "Trailing twelve-month revenue" (the number word in a measurement window) and "The certificate figures match" (a rule meant for "seven figures" matched any word before "figures").
- **Why the tests missed it.** Every test sentence was written by people who knew the rules. The stand-in reader and scripted responses never produce prose of their own, so they cannot surface a phrase a real model reaches for.
- **What changed.** Both rules were narrowed to the forms that state an amount ("seven figures", "a six-month runway" stay refused), each with tests for the live sentences and for the amounts that must still be refused. The lesson in `an-allowance-for-honest-text-is-a-hole.md` still applies: each narrowing is a possible hole, so each came with its refusal tests.
- **Rule.** Before trusting a guardrail's refusal rate, run each agent against a real model on a handful of borrowers and read every refusal. Treat a refused honest sentence as a defect with the same weight as a hole. Keep the refused text: it is the test case.
- **Also found.** A run's input was recorded as 4 tokens because the prompt was written to the cache and only uncached input was counted. Cache-written tokens now count as input; a run's cost cannot be read from a record that leaves them out.
